# revelaisp.com

The site for [Revela ISP](https://github.com/lanserge/revela), served by
GitHub Pages from this repository's default branch, with `CNAME` pointing
at the apex domain and Cloudflare in front — the same shape as
`bayerlink.github.io` and `edacommons.github.io`.

Static by intent: one `index.html` with its CSS inline, the mark, and the
demo video. Nothing to build, nothing to keep up to date, nothing that can
break between a commit and a page load.

`demo.mp4` is a web encode (1080p30, ~37 MB) of the recording made on
2026-08-15 — camera to screen through the generated ISP. The full-quality
capture is kept outside this repository; GitHub refuses files over 100 MB
and a web page should not serve one anyway.
